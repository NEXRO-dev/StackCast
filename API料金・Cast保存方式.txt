Tsundoku / StashCast
API料金・Cast課金・保存方式メモ

作成日：2026-08-10

==================================================
1. Cast生成の基本方針
==================================================

ユーザーがストックした記事を3件以上選択し、1つのCastを作成する。

Cast生成の流れ：

1. 選択された記事の本文をバックエンドで取得・整形
2. OpenAI API（予定モデル：gpt-5.6-luna）で要約・Cast台本を作成
3. Fish Audio APIで台本を音声化
4. MP3として生成
5. Cloudflare R2へMP3をアップロード
6. Tursoには音声ファイル本体を保存せず、R2のobject keyとURLのみ保存
7. アプリはバックエンドからCast情報を取得し、R2の音声URLを再生

APIキーはiOSアプリに含めず、必ずバックエンド側の環境変数で管理する。

==================================================
2. 想定している1回のCast
==================================================

- 記事数：3〜4記事
- 標準音声時間：約10分
- 日本語台本：約3,000〜5,000文字
- 出力形式：MP3

10分を超えるCastは、使用時間に応じて複数クレジットを消費する。

==================================================
3. API原価の概算
==================================================

OpenAI GPT-5.6 Luna：

- 入力：1,000,000トークンあたり $1
- 出力：1,000,000トークンあたり $6
- 1Castあたりの概算：$0.03〜$0.05

Fish Audio S1 / S2：

- 1,000,000 UTF-8バイトあたり $15
- 日本語10分程度の音声：概算 $0.15〜$0.25

API合計：

- 1Castあたり：約 $0.17〜$0.30
- 赤字防止の計算では、通信・再試行・失敗分を含めて
  1Cast = $0.30として計算する

この金額には、R2保存料、R2通信料、Turso、Vercel、メール送信、
Apple手数料、税金などは含まれない。

Fish Audioの無料モデルや無料枠は、仕様変更の可能性があるため、
本番の事業計算では有料APIとして扱う。

==================================================
4. クレジット方式
==================================================

Castの長さごとにクレジットを消費する。

- 5分Cast：1クレジット
- 10分Cast：2クレジット
- 15分Cast：3クレジット
- 20分Cast：4クレジット

この方式により、短いCastを作るユーザーと長いCastを作るユーザーの
API原価を公平に扱える。

==================================================
5. 初期プラン案
==================================================

Free：

- 料金：$0
- 月3クレジット
- 10分Castのみ、または10分Cast相当まで
- まずCastの便利さを体験してもらうためのプラン

Plus：

- 料金案：$9.99 / 月
- 月40クレジット
- 10分Castなら月20本相当
- 5・10・15・20分のCastに対応
- オフライン再生
- URL保存期間を延長

Pro：

- 料金案：$14.99〜$19.99 / 月
- 月100クレジット
- 10分Castなら月50本相当
- 優先生成、長期保存、バックグラウンド再生など

Lifetime：

- 買い切りにする場合も無制限にはしない
- 累計クレジット、または月間クレジット上限を設ける
- 例：$99.99で累計100〜150クレジット

Plusは月200本ではなく、月40クレジットを基本案とする。

==================================================
6. 赤字防止の考え方
==================================================

クレジット上限はアプリ画面ではなく、バックエンドで必ず検証する。

Cast作成リクエスト時に以下を実行する：

1. ユーザー認証を確認
2. RevenueCatまたはTurso上の契約プランを確認
3. 現在の請求期間を確認
4. 残りクレジットを確認
5. 必要クレジットを仮予約
6. Cast生成に成功したら消費確定
7. 失敗したら仮予約を返却

生成中に同じリクエストを複数回送られても、二重消費・無制限生成が
起きないようにidempotency keyを使用する。

APIを呼び出す前にクレジットを確認する。クレジット不足の場合は、
OpenAIやFish Audioを呼び出してはいけない。

==================================================
7. 収支の基本式
==================================================

月間利益 ＝
  Apple手数料後の売上
  − OpenAI費用
  − Fish Audio費用
  − R2費用
  − Turso費用
  − Vercel等のサーバー費用
  − メール送信費用
  − その他固定費

API原価を1Cast $0.30として計算した場合：

- Free 3クレジット相当：最大約 $0.90 / ユーザー
- Plus 40クレジット：最大約 $6〜$12程度
- Pro 100クレジット：最大約 $15〜$30程度

実際の原価はCastの長さ、記事本文の長さ、再試行回数によって変わる。

Plus $9.99の場合、Apple手数料15%後の売上は約$8.49。
10分Castを20本作成するケースでは、API原価を約$6として、
サーバー費用などを差し引く前に約$2.49が残る。

したがって、Plusを月40クレジットにする場合は、価格を下げすぎない。

==================================================
8. R2 / Turso保存設計
==================================================

R2に保存するもの：

- Cast MP3本体
- 必要に応じてカバー画像や波形データ

R2 object key例：

casts/{userId}/{castId}/audio.mp3

Tursoに保存するもの：

- cast id
- user id
- タイトル
- 概要・台本の必要部分
- 音声時間
- 消費クレジット
- ステータス（queued / processing / completed / failed）
- R2 object key
- 再生用URL、または署名付きURL生成に必要な情報
- 作成日時
- 失敗理由

MP3本体をTursoのDBに保存しないことで、DBサイズの増加を抑える。

公開URLを恒久的に保存するよりも、R2 object keyを正とし、
再生時にバックエンドで有効期限付きの署名URLを発行する方式を推奨する。

==================================================
9. 実装時の注意点
==================================================

- Fish AudioとOpenAIのAPIキーをiOSアプリへ入れない
- Cast生成はバックエンドのジョブ処理にする
- アプリを閉じても生成が継続するようにする
- 生成中のCastをアプリに表示する
- 失敗時はクレジットを返却する
- 生成済みMP3を再生成しないため、同一記事・同一設定の重複を検知する
- R2の署名付きURLに有効期限を設定する
- 退会時のMP3削除方針を決める
- API使用量をユーザー単位・Cast単位で記録する
- 月末にOpenAI、Fish Audio、R2の実績費用を確認する

==================================================
10. 最初に決めるべき数値
==================================================

実装前に以下を確定する：

1. Plus価格：$9.99で開始するか
2. Pro価格：$14.99または$19.99か
3. Freeの月間クレジット数
4. Plusの月間クレジット数
5. Proの月間クレジット数
6. Lifetimeの累計クレジット数
7. 1Castあたりの記事数
8. 各Cast時間の実際の台本文字数
9. MP3の保存期間
10. R2の署名付きURLの有効期限

まずは実際に10〜20本のCastを生成し、OpenAIトークン数、Fish Audioの
UTF-8バイト数、MP3ファイルサイズ、生成失敗率を計測する。
その実績値を使って料金とクレジット数を最終決定する。
